## Tickbird 1.0.0 — first release

Tickbird is a cross-platform desktop client for exploring and managing time series databases. This first
release supports **InfluxDB 1.x (InfluxQL)** and **InfluxDB 3.x (SQL)** on **Windows, Linux and macOS**.

### Highlights
- Connections with groups (PROD, DEV, …), a dockable Object Explorer with filter, and a query history
  with expiry, export and import.
- Query editor with InfluxQL/SQL IntelliSense (including tag values), find and replace, and SSMS-style colors.
- Result grid with filtering, plus **Chart** and **Map** views of the same rows.
- Server administration: users and privileges, retention policies, continuous queries, backfill,
  running queries and diagnostics.
- Safer drops: type the database, measurement or series name to confirm.
- Date format: system default (the default), US, UK/FR/ES/IT, German, Dutch, ISO 8601 and more.
- Import your connections from InfluxDB Studio (**File → Import → From InfluxDB Studio**).

### Notes
- The builds are **not code-signed**. On Windows, SmartScreen may ask you to confirm; on macOS, right-click
  **Tickbird.app → Open** the first time (or run `xattr -cr Tickbird.app`).
- On Linux, extract the archive and run `./Tickbird/Tickbird.Desktop`. The map's street and satellite layers need
  an internet connection.
- This version installs as a new product next to any older InfluxDB Studio / Explorer installation.
