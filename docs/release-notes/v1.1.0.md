## Tickbird 1.1.0

### New
- **Favorite queries.** Mark queries in **View → Query History** with **☆ Add Favorite**, and show only them
  with **Favorites only**. Favorites never expire and are the last to be dropped when the history is full.
- **Safer deleting in the history.** Deleting a selection that contains favorites asks first, with an unticked
  box **Also delete the favorite queries**. **Clear All** now always asks, with the same box.
- **Epoch numbers as dates.** Right-click a cell or a column header › **Epoch Time › Show as Date/Time** to show
  a column of Unix epoch numbers (seconds, milliseconds, microseconds or nanoseconds, or auto-detect) as UTC dates in
  your date and time format. **Show as Number** goes back, and **Copy Cell as Date/Time** copies a single converted
  value. The choice is kept when you run the query again.

All downloads include the .NET runtime, and `SHA256SUMS.txt` lists the checksums. The builds are not code-signed:
on Windows SmartScreen may ask you to confirm, and on macOS right-click **Tickbird.app → Open** the first time.
